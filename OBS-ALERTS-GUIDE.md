## 🎯 Что такое Donation Alerts

Donation Alerts - это виджет который показывает анимированные уведомления на стриме когда кто-то делает донат.

**Возможности:**
- 💬 Текст с именем донатера, суммой и сообщением
- 🖼️ Картинка/GIF анимация
- 🔊 Звуковое оповещение
- 🗣️ TTS озвучка сообщения
- ✨ Анимации появления (fade, slide, bounce, zoom)
- ⚙️ Полная кастомизация (шрифт, цвет, размер, позиция)

## 🔗 Получение Widget URL

### Шаг 1: Зайти в Settings
1. Открой сайт: `http://45.144.52.219:3001`
2. Авторизуйся
3. Нажми **Settings** в хедере

### Шаг 2: Найти Widget URL
1. Перейди на вкладку **"Alerts"**
2. Найди секцию **"Widget URL for OBS"**
3. URL будет выглядеть так:
   ```
   http://45.144.52.219:3001/alerts/[username]?token=[ваш-секретный-токен]
   ```
4. Нажми **"Copy"** чтобы скопировать

⚠️ **ВАЖНО:** Не делись этим URL! Любой у кого есть токен может видеть твои донаты.

## 🎥 Настройка в OBS

### Вариант 1: Через меню Sources

1. **Открой OBS Studio**

2. **Добавь Browser Source:**
   - В панели **Sources** нажми **➕** (Add)
   - Выбери **Browser**
   - Назови его: `Donation Alerts`
   - Нажми **OK**

3. **Настройки Browser Source:**
   ```
   ☑️ Local file: [ ] (снять галочку)
   
   URL: [вставь свой Widget URL из Settings]
   
   Width: 1920
   Height: 1080
   
   FPS: 30
   
   ☑️ Shutdown source when not visible
   ☑️ Refresh browser when scene becomes active
   
   CSS: (оставить пустым)
   ```

4. **Нажми OK**

5. **Настрой позицию:**
   - В превью OBS растяни виджет на весь экран
   - Или оставь размер как есть (виджет прозрачный)

6. **Готово!** 🎉

### Вариант 2: Через URL (быстрый)

```bash
obs://addbrowsersource?url=http://45.144.52.219:3001/alerts/[username]?token=[token]&width=1920&height=1080
```
Просто замени `[username]` и `[token]` на свои и открой этот URL в браузере.

## ⚙️ Настройка внешнего вида

Зайди в **Settings → Alerts** и настрой:

### 📝 Текст
- **Font Size:** 24-72px
- **Font Family:** Arial, Roboto, Comic Sans, и др.
- **Text Color:** Любой HEX цвет (#ffffff)
- **Animation:** fade, slide, bounce, zoom

### 🖼️ Картинка
- **Enable Image:** вкл/выкл
- **Image:** Загрузи свою или выбери из библиотеки
- **Size:** 50-500px

### 🔊 Звук
- **Enable Sound:** вкл/выкл
- **Sound:** Загрузи свой или выбери из библиотеки
- **Volume:** 0-100%

### 🗣️ TTS (Text-to-Speech)
- **Enable TTS:** вкл/выкл
- **Voice:** Выбери голос (en-US, ru-RU, и др.)
- **Speed:** 0.5x - 2.0x
- **Volume:** 0-100%

### 📍 Отображение
- **Duration:** 3-30 секунд
- **Position:** top, center, bottom
- **Min Amount:** Минимальная сумма для показа ($1+)

## 🧪 Тестирование

### Кнопка Test Alert

1. Зайди в **Settings → Alerts**
2. Нажми кнопку **"Test Alert"**
3. В OBS должен появиться тестовый донат

**Если не появился:**
- Проверь что Browser Source добавлен в OBS
- Проверь что сцена с виджетом активна
- Проверь URL в Browser Source

### Реальный тест

1. Открой страницу доната: `http://45.144.52.219:3001/donate/[username]`
2. Сделай тестовый донат
3. Alert должен появиться в OBS

## 🐛 Troubleshooting

### ❌ Виджет не загружается в OBS

**Проблема:** Черный экран или Loading...

**Решение:**
1. Проверь URL - должен быть ТОЧНО как в Settings
2. Проверь интернет на компьютере
3. Откройбраузере отдельно - если работает, значит проблема в OBS
4. Перезапусти OBS
5. Попробуй удалить и заново добавить Browser Source

### ❌ Alert не появляется когда приходит донат

**Проблема:** Test Alert работает, но реальные донаты не показываются

**Решение:**
1. Проверь что в Settings установлена правильная минимальная сумма
2. Проверь логи на сервере:
   ```bash
   pm2 logs tipit-dev | grep "Alert"
   ```
3. Проверь что Browser Source активен (не спрятан)

### ❌ Звук не воспроизводится

**Проблема:** Виджет показывается, но звука нет

**Решение:**
1. Проверь настройки OBS Audio:
   - Правая кнопка мыши на Browser Source → Audio Monitoring → Monitor and Output
2. Проверь громкость в Settings → Alerts → Sound Volume
3. Проверь что звук загружен (URL не пустой)

### ❌ TTS не работает

**Проблема:** Сообщение не озвучивается

**Решение:**
1. TTS работает только на HTTPS или localhost
2. На HTTP (текущий сервер) TTS может не работать
3. Используй звуковые alerts пока не переведем на HTTPS

### ❌ Виджет показывается поверх всего

**Проблема:** Alert закрывает весь экран

**Решение:**
1. В OBS: правая кнопка на источнике → Transform → Edit Transform
2. Настрой Position и Size
3. Или в CSS добавь:
   ```css
   body { pointer-events: none; }
   ```

## 💡 Tips & Tricks

### Несколько сцен с alerts

Можешь добавить один и тот же Browser Source в несколько сцен:
1. Добавь в Scene 1
2. Правая кнопка → Copy
3. Переключись на Scene 2
4. Правая кнопка → Paste (Reference)

### Проверка подключения

Открой консоль браузера в OBS (правая кнопка → Interact → F12) и посмотри логи:
```
✅ SSE connected
📨 SSE message received: {...}
🔔 Showing alert: {...}
```

### Кастомный CSS (для продвинутых)

Можешь добавить свой CSS в Browser Source:
```css
/* Убрать скругление углов */
.alert-card {
  border-radius: 0 !important;
}

/* Изменить фон */
.alert-card {
  background: linear-gradient(to right, #ff0000, #00ff00) !important;
}
```

## ❓ FAQ

**Q: Могу ли я использовать виджет на нескольких компьютерах?**
A: Да, токен работает на любом устройстве.

**Q: Как сбросить токен если кто-то его узнал?**
A: Сейчас нельзя, но скоро добавим кнопку "Regenerate Token" в настройках.

**Q: Можно ли изменить размер alert виджета?**
A: Да, в OBS просто перетащи углы источника.

**Q: Работает ли виджет офлайн?**
A: Нет, нужен интернет для подключения к серверу.

**Q: Можно ли использовать свои шрифты?**
A: Пока нет, но планируется добавить.
